# 白話對照表(詞庫,持續累積)

> 每週遇到新術語就加進這份文件,長期變成專屬詞庫。敘事生成時會整份附在 system prompt 後面當參考。

| 術語 | 白話說法 |
|---|---|
| MA200 / 200 日均線 | 過去 200 天的平均成本,長期抱著的人平均賠賺的分水嶺 |
| LH / LL(低高、低低) | 想漲漲不上去、想守守不太住 |
| 負資金費率 | 做空的人還在倒貼錢給做多的人,代表沒什麼人相信這波漲勢 |
| RS 強弱排名 | 這禮拜錢跑去哪個產業,市場用鈔票投票的結果 |
| 帶量突破 | 不只是漲,是很多人同時搶著買才推上去的,比較有支撐力 |
| ATH(歷史新高) | 從來沒有人在這個價位買過,賣的人全部是賺錢的 |
| 貼水 / 升水 | 現在買比較貴還是比較便宜,跟未來預期有關 |
| 軟著陸 | 經濟降溫但沒有真的摔倒,是大家都在賭的「最佳劇本」 |
| 支撐 / 壓力 | 價格「卡住」的樓層——支撐是地板,壓力是天花板 |
| Risk-off / 資金轉防禦 | 大家開始怕了,把錢從「賭大」的資產搬去「穩」的資產 |
